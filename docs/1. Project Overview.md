# Project Overview

You’ve just joined an AI team that’s building an internal assistant for employees at your company. This assistant must answer employee questions using company documents — but before it can generate an answer, it needs a way to find the most relevant documents for each question.

That’s your job: **build the semantic retriever**.

In this project, you’ll complete a pipeline that:

- Encodes queries and documents using transformer embeddings
- Retrieves top-k meaning-related documents using cosine similarity
- Evaluates performance using Recall@k
- Visualizes the embedding space
- Explains the retriever’s role in a Retrieval-Augmented Generation (RAG) system
